# DEC-003 — Portal Composition

## Status

Accepted

## Decision

Ketiga portal menggunakan component library dan semantic system yang sama.

Perbedaan hanya diterapkan melalui:

- layout;
- navigation;
- density;
- content width;
- heading scale;
- surface composition;
- information emphasis.

Tidak dibuat sistem button, form, status, font, atau icon terpisah.
