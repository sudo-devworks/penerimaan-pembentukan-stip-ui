# High-Fidelity Public Website

Implementasi ini merupakan baseline High-Fidelity Public Website untuk sistem
Penerimaan Pembentukan STIP.

## Scope

Public Website menyediakan halaman:

- Beranda;
- Daftar Kegiatan;
- Detail Kegiatan;
- Daftar Program;
- Detail Program;
- Persyaratan Pendaftaran;
- Alur Pendaftaran;
- Jadwal dan Tahapan Seleksi;
- Biaya Pendaftaran;
- Daftar Pengumuman;
- Detail Pengumuman;
- Pertanyaan Umum;
- Bantuan dan Kontak;
- Halaman Tidak Ditemukan.
