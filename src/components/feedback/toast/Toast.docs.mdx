## Penggunaan

Gunakan untuk:

- data berhasil disimpan;
- perubahan berhasil diterapkan;
- tindakan sederhana gagal;
- feedback singkat setelah user melakukan action.

Jangan gunakan Toast untuk:

- informasi kritis yang wajib dibaca;
- validation error form;
- instruksi panjang;
- blocking error;
- hasil proses besar yang membutuhkan next step.

## Duration

Default:

```text
5000 ms
```
