`Breadcrumb` menunjukkan posisi halaman saat ini di dalam hierarki informasi.

Breadcrumb digunakan untuk membantu user memahami hubungan halaman saat ini
dengan halaman induknya.

## Semantics

Struktur dasarnya:

```html
<nav aria-label="Breadcrumb">
  <ol>
    <li>
      <a href="/">Beranda</a>
    </li>

    <li aria-current="page">Detail Peserta</li>
  </ol>
</nav>
```
