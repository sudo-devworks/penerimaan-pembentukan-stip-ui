# Form Components

Form Components merupakan reusable form system untuk:

- Public Website;
- Portal Peserta;
- Portal Internal.

Seluruh component menggunakan prinsip:

- native semantic first;
- accessible label wajib;
- token-based styling;
- responsive;
- density inheritance;
- shared system dengan composition berbeda;
- WCAG 2.2 Level AA sebagai target.

## Component Inventory

### Field Foundation

- FormField
- FormLabel
- HelperText
- RequirementMessage
- ErrorMessage
- RequiredFieldsNote
- ErrorSummary

### Input Controls

- TextInput
- PasswordInput
- SearchInput
- Textarea
- Select
- Checkbox
- CheckboxGroup
- Radio
- RadioGroup
- FileInput

### Layout

- FieldGroup
- FormSection
- FormActions

## Architecture

```text
Semantic Tokens
↓
Form Component Tokens
↓

↓
Input Components

Form Composition
```
